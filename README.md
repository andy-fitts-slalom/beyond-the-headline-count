# Beyond the Headline Count

P302 interactive editorial story for the entirely fictional Meridian Signal Group. All campaigns, outlets, articles and annotations are invented. Vue 3, TypeScript, Vite and D3/SVG.

See [BRIEF.md](BRIEF.md) for the specification and [docs/PROGRESS.md](docs/PROGRESS.md) for current implementation and publication status. Original prototype code is MIT licensed; dependencies retain their own licenses.

Implementation and deployment are in progress. No live URL is verified yet.
